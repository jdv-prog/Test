# Friends at Hand

Events, volunteers and budgets, together. A mobile-first web app for small volunteer-run groups.

- What we're building: [SPEC.md](SPEC.md)
- How: [PLAN.md](PLAN.md)
- Where we are: [PROGRESS.md](PROGRESS.md)

## Run it on your computer
Needs [Node.js](https://nodejs.org) (the "LTS" version).

```
npm install
npm run dev
```
Then open http://localhost:5173 in your browser.
